# BREU — Distrito Fantasma

Jogo de terror 3D para navegador, ambientado em uma cidade futurista abandonada, com becos estreitos, cabos suspensos, pichações, iluminação instável e neblina.

## Jogar

Acesse https://breu-noite-game.vercel.app

## Desenvolvimento

Projeto estático: abra `index.html` em um navegador compatível com WebGL2, ou hospede os arquivos em um servidor HTTPS.

- Exploração em primeira pessoa, lanterna, perseguição e missão cooperativa.
- Layout adaptado para computador e celular.
- Salas WebRTC/PeerJS (até 4 pessoas), dependentes do serviço de sinalização e das condições de rede.

> **Status:** versão experimental. Conectividade online entre aparelhos reais ainda requer testes. Não há garantia de que conexões funcionem em todas as redes.

## Publicação

Site estático para Vercel, sem etapa de compilação. Arquivos do projeto são disponibilizados na raiz.
